# 이직·실업급여 온톨로지

이직·실업급여의 요건, 급여 계산, 절차와 의무를 적용 시점별 법령 근거에 연결한 온톨로지의 탐색 화면이다. 화면 이름은 다루는 범위를 그대로 쓴다. 구직급여 상한액은 현재 연결한 예제 하나다.

`/view/`에서 AI 노동법 상담의 실제 응답, 지식 그래프, 모델 응답을 함께 본다.

현재 API는 예제의 이직일을 받아 상한액과 정해진 근거를 확인한다. 자유질문을 지원하려면 질문별 근거 검색, 적용 시점 판단, 탐색 기록 생성과 답변 검증을 추가해야 한다. 자유질문 화면에서는 비교 패널과 예제 전용 상한액 영역을 사용하지 않는다. 외부 상담은 공식 서비스 링크로 열며, 현재 공개 연동 API는 확인하지 못했다.

## 실행

```powershell
uv run python -X utf8 view/serve.py
```

[로컬 화면](http://127.0.0.1:8765/view/)을 연다. 서버는 `127.0.0.1`에서 `view/`만 제공한다.

## 시작 화면

첫 진입은 노드 지구본 회전, 한국 확대, 한반도 윤곽 강조를 거쳐 약 2.4초에 화면을 연다. 지구본의 대륙은 [Natural Earth 1:110m land](https://www.naturalearthdata.com/about/terms-of-use/)를 사용하며 public domain이다. 세계 노드의 밝기는 장식이고 인구 측정값이 아니다. 한국은 기존 WorldPop 기반 심벌의 노드·명암·윤곽을 사용한다. 생성기는 `scripts/build_intro.py`, 웹용 좌표는 `assets/intro-geometry.json`이다. 화면에서 외부 지도 서비스로 요청하지 않는다.

데이터, 그래프 첫 그리기, 주요 이미지와 글꼴이 준비되기 전에는 본 화면을 가린다. 같은 탭에서 다시 방문하면 지도만 표시하는 짧은 전환을 사용한다. 건너뛰기나 Escape는 연출을 줄이며 준비 완료 조건은 유지한다. 동작 줄이기를 설정한 사용자는 회전·확대 없이 진입한다. 초기화 오류는 바로 표시하고, 12초 이상 지연되면 인트로를 닫고 안내한다. 스크립트 자체를 읽지 못한 경우에도 15초 뒤 화면을 해제한다. 전체 연출은 `/view/?intro=1`에서 다시 볼 수 있다.

## 사용

이직일을 고르고 질문하기를 누른다. 왼쪽에는 저장한 응답이 재생되고, 오른쪽에는 NVIDIA 모델의 실제 응답이 표시된다. 가운데는 규칙 실행 기록에 따라 해당 노드로 이동한다. 기본 단계 간격은 1,100ms이며, 배속·일시정지·단계 선택을 지원한다. 현재 예제는 첫 단계부터 마지막 단계까지 5.5초, 마지막 화면 이동까지 약 6초다. 하단은 한 줄로 시작해 도달한 단계마다 구간을 추가하고 320ms 동안 너비를 나눈다. 구간 수는 실행 기록에서 읽으며, 완료율이 아닌 단계 번호를 표시한다. 실행 기록은 먼저 계산되고 그래프 연출이 그 순서대로 진행된다.

모델 요청에 포함한 근거 ID를 서버가 알리면, 해당 근거가 탐색 단계에서 강조될 때 답변 생성 표시로 빛이 이동한다. 실제 노드와 표시 아이콘의 화면 좌표를 매 프레임 읽으며 이동은 590ms, 도착 강조는 560ms다. 모델 요청은 한 번이며, 이 효과는 이미 보낸 근거와 답변의 연결을 나타낸다. 단계마다 새 정보를 보내거나 모델이 그 노드를 읽었다는 신호는 아니다. 응답 완료·실패 시 효과를 끝내고, 탐색 기록만 재생할 때는 전송 효과가 나오지 않는다. 화면 밖으로 벗어난 출발점·도착점은 생략하고, 동작 줄이기에서는 이동 없이 색만 강조한다. 자유질문에서도 같은 연출을 쓰려면 실제 검색·근거 선택 과정에서 노드 ID와 단계 이벤트를 만들어야 한다.

노드를 호버하면 직접 연결된 노드와 간선이 강조된다. 설명창은 노드의 화면 좌표를 따라가며 가장자리에서 반대쪽으로 열린다. 클릭은 선택을 고정하고 상세를 연다. 빈 곳 클릭이나 Escape로 해제한다. 노드 좌표는 고정이다. 간선 위 빛 이동과 카메라 전환만 재생하며, 동작 줄이기 설정을 따른다. 그래프 우측 상단 버튼은 양쪽 답변을 접는다.

데스크톱에서는 두 패널 경계를 드래그해 답변 너비를 조절한다. 경계에 초점을 두고 방향키로도 조절할 수 있다. Shift를 누르면 40px씩, 기본은 10px씩 움직인다. Home/End는 최소/최대 너비, Enter나 두 번 클릭은 기본 비율로 되돌린다. 선택한 비율은 브라우저에 보관한다. 답변은 최소 200px, 그래프는 최소 320px를 유지한다. 800px 이하에서는 그래프 아래에 두 답변을 나란히 놓고, 500px 이하에서는 그래프·답변·AI 노동법 상담 순서로 쌓는다. 좁은 화면의 그래프 높이는 화면 높이에 맞춰 380~440px로 조절한다. 560px 이하에서는 날짜 선택과 질문하기 버튼을 같은 줄에 두며 터치 영역 높이는 44px다.

전체 보기 배율보다 더 축소할 수 없고, 확대 후 이동은 그래프 경계와 48px 여백 안으로 제한한다. 패널 너비나 창 크기가 바뀌면 제한도 다시 계산한다. 수동 탐색 중 크기를 조절해도 전체 보기로 초기화하지 않는다.

확대하면 일반 노드 이름도 표시한다. 연결 수가 많은 노드부터 이름을 배치하고 겹치는 이름은 줄인다. 이름이 잘 읽히도록 확대할수록 배경 연결선을 어둡게 한다. 호버·활성 연결선과 선택·활성 노드의 표시를 우선하며, 긴 이름의 전체 내용은 호버로 확인한다.

상단의 소개는 소개, 출처, 버전, 예제로 나뉜다. 노트 수와 법령 기준일은 그래프 데이터에서 읽는다. 출처 수와 검사 결과는 2026-11-09 확인값이다. 출처에는 법제처 국가법령정보센터, 공동활용 API, 고용24의 세 안내 원문 링크를 둔다. 법령 19개는 핵심 법령 6개와 참조 법령 13개다. 대상 조문 171/171 인용과 역량 질문 24개 통과는 지정된 범위의 검사이며, 모든 질문에 대한 답변 정확도를 뜻하지 않는다. 시나리오 3개 가운데 자동 단계 연결 검사가 읽는 것은 `sc-01`이므로 전체 시나리오 통과로 표시하지 않는다.

v0.1(2026-11-09)은 현재 탐색 화면과 지식 범위를 소개하는 첫 표시 버전이다. 법령 기준일 2026-10-14와 구분한다. 화면은 현재 제공과 제공 예정으로 나눈다. 제공 예정 항목은 기존 지식을 활용한 상용근로자·사업주 예제 추가, 심사·재심사 등 세부 절차 확장, 미해결 해석의 추가 근거 확인이다. 일정이나 완료를 확정한 표시는 아니다. 내부의 `draft`는 수집 예정이 아니라 원문 대조 전 상태이며, `verified` 노트에도 미해결 질문이 남을 수 있다.

## 실제 비교 응답

하단의 상한액·소요 시간·기록 영역은 각 응답이 완료된 뒤에만 표시한다. 초기 화면과 생성 중에는 빈 결과 영역을 남기지 않는다. 두 응답이 모두 완료되면 상한액 차이를 표시한다.

출처는 [고용노동부·한국공인노무사회 AI 노동법 상담](https://ai.moel.go.kr/llc/labor-law-chat)이다. 고용24 자체 챗봇으로 표기하지 않는다. [공식 소개](https://www.korea.kr/news/customizedNewsView.do?newsId=148948745)는 실업급여를 상담 대상에 포함한다. 비교 패널 제목에서 실제 서비스로 이동할 수 있다. 저장한 응답이라는 설명은 예제 정보에 둔다.

`data/baseline-responses.json`에 2026-11-09 질문별 새 대화에서 받은 응답과 화면 표시 시점을 저장했다. 전송 버튼을 누르기 직전부터 응답의 HTML 변화를 관측했으며, 마지막 글자가 나타난 뒤 5초 이상 변화가 없음을 확인했다. 원본 관측과 복사 버튼으로 얻은 마크다운, 캡처는 `data/captures/moel-2026-timed.*`와 `moel-2025-timed.*`에 보관한다. 앞선 미측정 응답도 별도 파일로 보존했다. `scripts/build_baseline.py`는 원문의 시각과 문구를 유지하고 표시용 HTML의 태그와 링크만 제한한다. 화면은 고정 타이핑 간격 대신 기록된 시점대로 표시한다. 동작 줄이기 설정에서도 같은 완료 시점까지 기다린 뒤 전체 응답을 표시한다.

2026년 질문은 첫 글자 1.815초·마지막 글자 3.605초, 2025년 질문은 1.543초·3.886초로 관측했다. 응답 중 최대 관측 간격은 각각 22ms·18ms다. 자동화 입력·관측 오버헤드가 포함된 사용자 화면 관측값이며 서버 내부 생성 시간이 아니다. 같은 질문을 이전에도 보냈으므로 캐시 사용 여부는 알 수 없다. 질문별 1회 측정이며 평균 속도나 서비스 성능 평가로 일반화하지 않는다. 좌측은 저장된 관측, 우측은 현재 호출의 공급자 요청부터 완료까지로 측정 구간도 다르다.

2026-09-30, 2025-12-31 이직 질문 모두 해당 서비스는 66,000원이라고 답했다. 이 화면은 선택한 이직일의 규정으로 68,100원 또는 66,000원을 산정한다. 전체 서비스의 정확도나 속도 우열을 산출하는 평가는 아니다.

2026-11-09에 [고용노동부의 시행령 개정 안내](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18736)와 [1350 상담 답변](https://1350.moel.go.kr/rtmview.do?id=1000324861)으로 상한액을 교차 확인했다. 후자는 2026-01-01 이후 이직자의 68,100원과 종전 이직자의 66,000원, 각 기초일액을 모두 명시한다. 이 검증은 구직급여 상한액과 적용 날짜에 한정한다. 다국어 품질이나 전체 상담 정확도는 평가하지 않았다.

## 모델

```dotenv
LLM_PROVIDER=nvidia
NVIDIA_API_KEY=
NVIDIA_MODEL=nvidia/nemotron-3-ultra-550b-a55b
NVIDIA_THINKING=true
```

[NVIDIA Nemotron 3 Ultra](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3-ultra-550b-a55b)를 사용한다. 2026-11-09 현재 키로 실제 호출과 한국어 답변을 확인했다. Kimi K2.6은 모델 목록에 있었지만 이 계정의 호출은 404를 반환했다. 모델이나 공급자를 자동으로 전환하지 않는다.

키는 서버에서만 읽는다. 모델에는 왼쪽과 동일한 질문, 서버가 계산한 결과, 관련 법령 발췌 4개를 보낸다. 핵심 금액과 근거 키를 검사한 뒤 응답을 표시한다. 요청에 실패하면 오류를 표시하며 정해 둔 문장을 모델 응답처럼 대신 보여주지 않는다. 응답 시간은 공급자 요청부터 완료까지이며, 화면 재생 시간과 별개다.

우측의 상태 표시는 실제 처리 신호에 따른다. NVIDIA 요청을 시작할 때 답변 요청 중, 스트림의 `reasoning_content` 또는 `reasoning`이 도착할 때 추론 중, `content`가 도착할 때 답변 작성 중, 결과 검증을 시작할 때 금액·출처 확인 중으로 바뀐다. 추론 원문은 저장하거나 브라우저로 보내지 않는다. 타이머로 상태를 넘기지 않으며, 추론 신호가 없는 응답은 추론 중으로 표시하지 않는다. Gemini는 현재 완료 응답만 받으므로 확인할 수 없는 중간 상태를 표시하지 않는다. 상태별 경과 시점은 내려받는 기록의 `modelResponse.phases`에 담는다. 방식은 [NVIDIA 공식 스트리밍 예제](https://build.nvidia.com/nvidia/nemotron-3-ultra-550b-a55b/build)에 따른다.

요청은 회청색, 추론은 민트색, 답변 작성은 하늘색, 금액·출처 확인은 연보라색으로 표시한다. 배경·테두리·아이콘의 색을 함께 전환하고, 단계 문구에는 200ms의 짧은 전환을 적용한다. 근거 도착 강조도 현재 단계의 색을 따른다. 실제 단계가 빨리 끝나면 그대로 다음 상태를 표시하며 색을 보여 주기 위해 응답을 늦추지 않는다.

아이콘은 추론 중에 노드와 연결선을 차례로 밝힌다. 삼각형 안쪽 점은 시각적 중심에 두고, 답변 작성으로 전환되면 노드들이 420ms 동안 아이콘 정중앙의 한 점으로 모인다. 중심점에서 옅은 파동이 퍼지고, 금액·출처 확인 중에는 점 주위로 빛이 돈다. 모두 실제 상태 이벤트에 연결하며, 동작 줄이기에서는 단계별 정지 형태만 표시한다.

Gemini는 `LLM_PROVIDER=gemini`로 직접 선택할 때만 사용한다. 무료 NVIDIA 키의 대안으로 자동 호출하지 않는다.

## 데이터

`scripts/export_view.py`는 `wiki/`의 1,371개 노드와 frontmatter wikilink를 내보낸다. 관계 7,898개는 출발·도착 노드, property, 인용 anchor별 중복을 제거한 수다. 실제 좌표 배치를 저장하며 시나리오의 근거 노드만 읽기 좋은 위치에 둔다. 그래프의 6단계는 이 질문의 날짜 판단·버전 선택·계산 기록이다. 모델의 사고 과정이나 범용 검색 기록이 아니다.

법령 발췌는 볼트의 정확한 인용 block에서 읽는다. 종전 제68조는 `data/historical-cap.json`의 법제처 응답 발췌를 사용한다. 출처 버전·hash·URL을 포함하며 `wiki/`의 현행 규칙을 수정하지 않는다. 수급자격과 실제 지급액은 다루지 않는다.

공식 로고와 상담 아이콘은 `assets/sources.json`에 원본 URL을 기록했다.

## 심벌

한반도의 노드 크기와 밝기는 [WorldPop의 2020년 인구 추정치](https://doi.org/10.5258/SOTON/WP00840)에 따른다. 출처는 WorldPop, University of Southampton, Bondarenko et al. (2025), Global2 R2025A v1이며 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)에 따라 가공했다.

남북한의 1km 인구 자료를 투영 좌표의 20km 구간으로 합산하고 육지 면적으로 나눴다. 지도는 같은 출처의 경계를 사용한다. 거주지가 없는 곳의 누락값도 육지 면적에는 포함한다. 인구 밀도를 로그 변환해 노드의 크기와 밝기에 반영하고 5,000명/km²부터는 최대 밝기를 적용한다. 지역 간 명암 격차를 줄이기 위해 노드 반지름은 0.50~0.90, 불투명도는 0.58~0.82로 제한했다. 작은 섬은 아이콘 크기에서 단순화했고 연결선은 장식이며 이동량을 뜻하지 않는다.

집계값, 원본 URL과 hash는 `assets/brand-population.json`에 보관했다. `python scripts/build_brand.py`로 SVG를 다시 만들 수 있다. 원본 GeoTIFF와 경계를 `.cache/brand/`에 두고 `--aggregate`를 사용하면 다시 집계한다. 이때만 Pillow와 NumPy가 필요하며 웹 실행에는 필요하지 않다.

uv run python -X utf8 -m pytest tests/test_view.py
